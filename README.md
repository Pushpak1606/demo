# Medscope Platform Frontend

Welcome to the Medscope next-generation healthcare platform frontend. This robust Next.js 14 (App Router) application brings a fully responsive, highly polished, and accessibility-first user interface for both Patients and Doctors.

## Features Completed
- **Public & Authentication:** High-conversion landing page and multi-step registration flows for both Patient and Doctor portals.
- **Patient Portal:** Comprehensive dashboards covering health metrics, dynamic timeline reminders, AI medicine assessments, nutrition tracking, Tiptap-powered daily journaling, specialized community group boards, and an overlay AI assistant.
- **Doctor Portal:** Granular practice management tools including AI-prioritized patient alert pipelines, calendar agendas, detailed single patient views, staff delegation controls, and a community moderation panel.
- **Telemedicine:** Native mockups of the secure live 1:1 video consultation rooms with split chat features.
- **Design System:** Custom tokens integrated via Tailwind CSS configured on top of shadcn/ui primitives.

## Prerequisites
- Node.js (v18.17 or later)
- pnpm (fast disk space efficient package manager)

## Getting Started

1. Set up dependencies:
```bash
pnpm install
```

2. Run the development server:
```bash
pnpm run dev
```

3. Open your browser:
Navigate to [http://localhost:3000](http://localhost:3000)

Enjoy experiencing Medscope!
